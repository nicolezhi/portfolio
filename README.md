# Portfolio

Product design portfolio built with Next.js (App Router), React, TypeScript, and Tailwind CSS.

## Getting started

Node.js is installed locally at `~/.local/node` because it was not already on your PATH. In a new terminal:

```bash
export PATH="$HOME/.local/node/bin:$PATH"
npm run dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000).

## Scripts

- `npm run dev` — start the development server
- `npm run build` — production build
- `npm run start` — serve the production build
- `npm run lint` — run ESLint

## Where to edit

- `src/lib/site.ts` — site name and description
- `src/content/case-studies.ts` — case study entries
- `src/app/globals.css` — design tokens
- `src/components/` — navigation, homepage, case studies, animation, and UI
